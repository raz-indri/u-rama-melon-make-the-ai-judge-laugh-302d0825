# Make the AI Judge Laugh

One joke about office life, one line, under 200 characters — the winner of a 6-draft duel test judged on the published judge brief (true observation, surprising turn, tight, original). The winning line turns the out-of-office auto-reply into a loop: the inbox itself emails you asking if you saw the email about your out-of-office reply.

Run it with `python3 main.py`; it writes the joke to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) after a self-check (one non-blank line, 1–200 characters).
